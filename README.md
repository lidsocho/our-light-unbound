# Our Light UnBound

An interactive digital catalogue for the **Our Light UnBound** art exhibition, showcasing works by 30+ BIPOC artists.

**Exhibition Dates:** January 9-31, 2026

## About the Exhibition

This exhibition is about tapping into that piece of ourselves that we turn to in times of trouble. That part of ourselves that believes peace will return, that inspires us to believe, hope, and dream again.

And once we are whole that part shines brightly. It is our light and when we are free it is unbound.

## Features

- Browse artwork by artist with expandable accordion sections
- Search functionality to filter artists and artworks by name, medium, or description
- Click any artwork image to view full-size in a modal
- Gallery hours and upcoming events information
- Responsive design for mobile and desktop
- Interactive Tag Wall community artwork

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- React Router

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
